自动保存保留恢复草稿，不会把空描述填成“无变化”。正式保存需要五条非空、互不重复的描述。

JSON 导出保持原始结构；CSV 逐句导出不包含 tokens。导出不包含未正式保存的草稿。最近 30 个完整 JSON 备份保留在 backups 目录。

这是单机单写入者工作区。团队成员应使用独立保存目录，勿通过网络盘同时修改同一份 JSON。
